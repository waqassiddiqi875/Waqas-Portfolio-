# BSSE Portfolio Website

## Files
- `index.html` — page structure and content
- `style.css` — design, colors, layout, and responsive styles
- `script.js` — contact form interaction

## How to run
1. Extract the ZIP file.
2. Keep all three files in the same folder.
3. Open `index.html` in a web browser.

Note: The contact form currently displays a demo confirmation only. It does not send an email because no backend or email service is connected.
